# STREAMIOV Code

**Ein eigenständiger, öffentlich entwickelter Coding-Agent für STREAMIOV.**

STREAMIOV Code baut auf dem Open-Source-Projekt [OpenCode](https://github.com/anomalyco/opencode) auf und soll um STREAMIOV-spezifische Projektkenntnis, spezialisierte Agenten, nachvollziehbare Aufgabenplanung, sichere parallele Arbeit und überprüfbare Qualitätssicherung erweitert werden.

> **Hinweis zur Herkunft:** STREAMIOV Code ist ein unabhängiges Community-/Produktprojekt. Es wird nicht vom OpenCode-Team entwickelt, unterstützt oder betrieben und ist nicht mit diesem Team verbunden. OpenCode ist ein eigenständiges Projekt; die jeweiligen Urheberrechtshinweise und Lizenzbedingungen bleiben erhalten.

## Projektstatus

Dieses Repository ist öffentlich und befindet sich im Aufbau. Die OpenCode-Quellbasis wurde noch nicht importiert. Funktionen gelten erst dann als vorhanden, wenn sie implementiert und durch Tests oder nachvollziehbare Prüfungen belegt sind.

## Leitziele

- OpenCode als nachvollziehbare Upstream-Basis übernehmen und dessen MIT-Lizenzhinweise bewahren.
- STREAMIOV-Projektkontext und Architekturwissen strukturiert bereitstellen.
- Spezialagenten für Studio, Audio, KI, Spiele, Design, Sicherheit, Integration und Tests koordinieren.
- Aufgaben persistent speichern, Abhängigkeiten verfolgen und nach Unterbrechungen fortsetzen.
- Änderungen isolieren, Konflikte bei paralleler Arbeit vermeiden und unabhängige Reviews durchführen.
- Tests, Sicherheitsprüfungen und Release-Gates vor jeder Freigabe ausführen.

## Grundsätze

- Keine produktiven STREAMIOV-Dateien oder bestehenden Repositories ohne ausdrückliche Freigabe überschreiben.
- Keine Secrets, Tokens, Zugangsdaten oder privaten Nutzerdaten committen.
- Keine produktiven Cloudflare-, TikTok- oder GitHub-Einstellungen ohne gesonderte Freigabe ändern.
- Keine unbelegten Aussagen über Fertigstellung oder Testergebnisse.
- Externe KI-Modelle und APIs können eigene Gebühren, Limits und Nutzungsbedingungen haben. Eine kostenlose interne Nutzung von STREAMIOV Code bedeutet nicht automatisch kostenlose Modell-Inferenz.
